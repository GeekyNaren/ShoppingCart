🛒 ShoppingStore
ShoppingStore is a personal e-commerce project built with Angular, .NET Core Web API, MongoDB, and JWT authentication. It simulates a modern online shopping experience where users can browse products, search and filter items, manage their cart, and complete a checkout flow.

✨ Features
Product listing with categories
Search and filter functionality
Shopping cart management
Secure authentication with JWT
Checkout flow with order summary

🛠 Tech Stack
Frontend: Angular
Backend: .NET Core Web API
Database: MongoDB
Authentication: JWT

🎯 Purpose
This project is built as a personal learning initiative to strengthen full‑stack development skills and explore how e‑commerce platforms are structured end‑to‑end.
